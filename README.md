A tiny Node program that writes one word, `Bluffing`, to `/output/entry.txt` for make.fun's "One Word for Your Wi-Fi" bounty — one word, nothing else. Home Wi-Fi constantly shows full bars yet delivers no internet; it bluffs.

## Run it

```sh
node main.ts
```
